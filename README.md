# 🌿 Plant Disease Detection using AI & Deep Learning

An AI-powered Plant Disease Detection system that uses machine learning and deep learning techniques to identify plant diseases from leaf images. This project aims to support early disease identification and help improve plant health through image-based analysis.

## 📌 Project Overview

Plant diseases can affect crop quality and agricultural productivity. This project focuses on detecting plant diseases by analyzing images of plant leaves using an AI-based image classification model.

Users can upload a plant leaf image through a web interface and use the trained model to predict the corresponding disease class.

## ✨ Features

- 🌱 **Plant Disease Detection** — Analyze leaf images to predict plant diseases.
- 🤖 **AI-Based Classification** — Use a trained machine learning/deep learning model for image classification.
- 🖼️ **Image Upload** — Provide plant leaf images as input.
- 📊 **Prediction Results** — Display the model's predicted class.
- 💻 **Web Interface** — Access the project through a user-friendly interface.
- 🚀 **Early Identification** — Help users identify potential plant health problems.

## ⚙️ How It Works

1. Upload an image of a plant leaf.
2. The application processes the image.
3. The trained AI model analyzes the image.
4. The model predicts the plant disease class.
5. The prediction is displayed to the user.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Parmardurgesh06/plant_disease_detection.git
cd plant_disease_detection
```

### 2. Create a Virtual Environment

```bash
python3 -m venv venv
```

Activate the environment on macOS or Linux:

```bash
source venv/bin/activate
```

On Windows:

```bash
venv\Scripts\activate
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Application

Run the command corresponding to your application's entry point. For example, if your project uses Flask:

```bash
python app.py
```

If your project uses Streamlit, run:

```bash
streamlit run app.py
```

Check the application instructions and dependencies before running either command.
